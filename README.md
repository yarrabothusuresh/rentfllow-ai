# RentFlow AI

**"Turn every rental inquiry into a profitable booking."**

RentFlow AI is an AI-native rental operating system for US event and party rental companies.

## Setup

### Backend (Spring Boot)
1. Navigate to `backend/`
2. Run `mvnw spring-boot:run` (or `./mvnw spring-boot:run`)
3. The API will start on `http://localhost:8080`

### Frontend (Angular)
1. Navigate to `frontend/`
2. Run `npm install`
3. Run `npm start`
4. The application will start on `http://localhost:4200`
